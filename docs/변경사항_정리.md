### 변경 개요
- 로컬 SQLite(`simulation.db`)에서 데이터를 읽던 구조를 **AWS RDS(PostgreSQL)**에서 읽는 구조로 전환

## 6. 다른 PC에서 실행하기

### 준비물
- Python 3.9 이상
- Git (SSH 클라이언트 포함)
- snowman-pemkey.pem 키 파일

### 1단계: 프로젝트 복사
simulation 폴더를 통째로 가져가되, 제외해도 되는 것:
- `__pycache__/` 폴더들
- `simulation.db` (더 이상 사용 안 함)
- `.claude/` 폴더

### 2단계: 패키지 설치
```bash
cd simulation
pip install -r requirements.txt
```

### 3단계: SSH 키 경로 확인
`db.py`의 SSH 설정을 새 PC 환경에 맞게 수정:
```python
SSH_HOST = "54.116.93.66"          # EC2 퍼블릭 IP (변경될 수 있음)
SSH_USER = "ec2-user"
SSH_KEY  = "C:/path/to/snowman-pemkey.pem"  # ← 새 PC의 키 파일 경로
```

### 4단계: 서버 실행
```bash
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

### 5단계: 브라우저 접속
```
http://localhost:8000
```

### 주의사항
1. **EC2 퍼블릭 IP** — 탄력적 IP가 아니면 EC2 재시작 시 변경될 수 있음. db.py의 SSH_HOST 확인
2. **PEM 키 권한** — Windows에서 VSCode Remote SSH 등 사용 시 키 파일 권한 설정 필요:
   ```powershell
   icacls "경로\snowman-pemkey.pem" /inheritance:r /grant:r "사용자명:R"
   ```
3. **OpenAI API 키** — `services/ai_explanation.py`에 하드코딩됨. 만료 시 교체 필요
4. **포트 충돌** — 8000번(서버), 15432번(SSH 터널) 포트가 사용 중이면 변경
5. **placement_group의 user_id** — 현재 임시로 1 고정. Spring Boot 연동 시 변경 필요
